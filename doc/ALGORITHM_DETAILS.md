# SUPER算法细节文档

## 1. MINCO算法详解

### 1.1 算法原理

MINCO（Minimum Snap with Constrained Optimization）是一种基于最小急动度的轨迹优化算法。该算法通过优化轨迹的高阶导数（位置、速度、加速度、急动度、跃度）来生成平滑且可行的轨迹。

### 1.2 数学模型

#### 1.2.1 优化目标
```
min J = ∫(d^6x/dt^6)^2 dt
```

其中，J是最小急动度目标函数，通过对轨迹的六阶导数积分最小化来保证轨迹的平滑性。

#### 1.2.2 约束条件
- **边界条件**: 起始点和终点的位置、速度、加速度、急动度约束
- **连续性约束**: 相邻轨迹段在连接点处的连续性
- **安全约束**: 轨迹必须位于安全走廊（多面体约束）内
- **动力学约束**: 速度和加速度限制

### 1.3 MINCO_S4NU实现

#### 1.3.1 7次多项式表示
每一段轨迹使用7次多项式表示：
```
p(t) = a₀ + a₁t + a₂t² + a₃t³ + a₄t⁴ + a₅t⁵ + a₆t⁶ + a₇t⁷
```

其中，系数a₀...a₇通过边界条件和优化目标确定。

#### 1.3.2 约束处理
安全约束通过多面体表示：
```
Ai * p(t) ≤ bi, ∀i ∈ [1, n]
```

其中，Ai和bi定义了第i个平面的法向量和平面方程。

### 1.4 优化求解

#### 1.4.1 拉格朗日乘数法
使用拉格朗日乘数法处理约束优化问题：
```
L(x, λ) = f(x) + Σλi * gi(x)
```

#### 1.4.2 KKT条件
满足Karush-Kuhn-Tucker条件以获得最优解。

## 2. A*路径搜索算法

### 2.1 算法原理
A*是一种启发式搜索算法，结合了Dijkstra算法的准确性和贪心最佳优先搜索的效率。

### 2.2 评价函数
```
f(n) = g(n) + h(n)
```

其中：
- g(n): 从起始点到节点n的实际代价
- h(n): 从节点n到目标点的启发式估计代价

### 2.3 启发式函数类型
- **对角线距离**: 适用于允许8方向移动的场景
- **曼哈顿距离**: 适用于仅允许4方向移动的场景
- **欧几里得距离**: 适用于允许任意方向移动的场景

### 2.4 3D网格优化
- **体素化处理**: 将3D空间划分为规则网格
- **邻域搜索**: 支持6连通、18连通、26连通邻域
- **地图类型**: 支持占用地图和概率地图

## 3. 双层规划架构

### 3.1 探索轨迹 (ExpTraj)
- **目标**: 生成主要导航轨迹
- **优化策略**: 在已知环境中寻找最优路径
- **约束**: 速度、加速度限制，安全走廊约束

### 3.2 备份轨迹 (BackupTraj)
- **目标**: 提供应急安全轨迹
- **触发条件**: 检测到潜在危险或探索轨迹失效
- **优化策略**: 快速生成安全返回路径

### 3.3 动态切换机制
- **状态监测**: 实时监测轨迹可行性和环境变化
- **平滑过渡**: 保证轨迹切换时的连续性
- **优先级管理**: 根据安全等级动态调整轨迹优先级

## 4. 安全走廊生成

### 4.1 多面体表示
使用H-representation（半空间表示）：
```
Ax ≤ b
```

其中，A是法向量矩阵，b是截距向量。

### 4.2 走廊构建算法
- **线段扩张**: 基于机器人尺寸扩张路径
- **多面体交集**: 计算相邻线段扩张区域的交集
- **凸包计算**: 生成最小凸包围盒

### 4.3 FOV裁剪
根据传感器视场角裁剪安全走廊，避免盲区。

## 5. 时间分配策略

### 5.1 PM时间分配器
使用简单PM（Point-Mass）时间分配器：
```
t = (v_max - v_initial)/a_max + (s - s_initial)/v_max
```

### 5.2 动态调整
根据实时环境信息动态调整时间分配，确保轨迹的可行性。

## 6. 梯度计算

### 6.1 目标函数梯度
通过链式法则计算目标函数相对于优化变量的梯度：
```
∇f = (∂f/∂c) * (∂c/∂x)
```

### 6.2 约束函数梯度
对约束函数进行梯度计算，用于优化求解。

## 7. 数值稳定性

### 7.1 条件数控制
通过预处理和正则化技术控制优化问题的条件数。

### 7.2 收敛性判断
- **梯度范数**: 梯度小于阈值
- **变量变化**: 变量更新幅度小于阈值
- **目标函数**: 目标函数改善小于阈值

## 8. 性能优化

### 8.1 预计算
- **矩阵分解**: 预先分解系数矩阵
- **缓存机制**: 缓存常用的计算结果
- **稀疏性利用**: 利用矩阵的稀疏结构

### 8.2 并行化
- **多段并行**: 各轨迹段可并行计算
- **向量化**: 利用SIMD指令加速矩阵运算
- **异步处理**: 非关键路径异步执行
