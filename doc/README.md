## 快速开始

1. **了解系统**: 从[系统架构文档](SYSTEM_ARCHITECTURE.md)开始了解项目整体设计
2. **学习算法**: 阅读[算法细节文档](ALGORITHM_DETAILS.md)理解核心技术
3. **配置项目**: 使用[配置指南](CONFIGURATION_GUIDE.md)设置合适的参数
4. **开发调试**: 参考[开发与调试指南](DEVELOPMENT_DEBUGGING.md)进行开发
5. **性能优化**: 需要时查阅[性能优化指南](PERFORMANCE_OPTIMIZATION.md)提升性能
